# Abinaya's Portfolio

A simple single-page portfolio built using HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. The images and Google Fonts require an internet connection.

## Sections
- Hero
- My journey
- Things I like
- Family
- Hobbies
- Projects
- Footer

## Theme
The theme colours are managed in `css/theme.css` using CSS variables. A light and dark theme are included.

## GitHub Pages
Enable GitHub Pages from the repository settings and select the branch/folder containing the site files.
